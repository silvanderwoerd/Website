Written 28 Oct 2026 from a fresh copy of the live site (`reference/live-site/`,
saved the same day by `scripts/save-live-site.ps1`, because Sil's 3 Oct copy
wasn't on this computer). The per-page stripe lists are in
[inventory-pages.md](inventory-pages.md), generated by
`scripts/inventory/stripe-lists.ps1`.

## In one paragraph

The 253 addresses are **247 real pages, 4 redirects and 2 broken addresses**.
They come from **11 layouts**, fewer than the 12–15 we expected, because all 30
project pages turn out to share one skeleton (hero → details → film → *free
stripes* → next project). Only two layouts are real Webflow templates (Post and
Category). Everything else was built by hand, page by page. Across the whole site
there are **about 30 stripe types**. 12 of them carry almost every page, and
about 15 appear on a single page only.

### What the project pages have in common

Counts below include Earth Defender, which uses the same stripes (31 pages).

- **Always** (31/31): project-details, gallery, text, next-project (really a
  "View More Work" button). Project-hero and a large film open every `/work/*`
  project; Earth Defender opens with statements instead, and Change Drivers puts
  its stats before its films.
- **Often**: quote (22), campaign (13), text-on-image (11), cta-small (11),
  video(medium) (11), stats (10), cta-big (8), posters (7), video(split) (6).
- **Rare**: phones (3), instafilter (1, Total Pollution), embedded website (1,
  Team Forest), and text+video ×11 (Change Drivers' episode list).
- Order and count vary freely: Dangerous Lies alternates text/gallery 6 times,
  and Change Drivers is 11 episodes and 9 extra films. So **a project's content
  file is its own stripe list**, as CLAUDE.md says, not a fixed set of fields.

## 4. Webflow interactions (what moves, when)

All 785 interaction triggers live in one Webflow file (`webflow.schunk.4d8d…js`,
800 KB, saved in `reference/live-site/_assets/`). Grouped by what they do:

| Family | Webflow names | Trigger | What moves | Becomes original |
|---|---|---|---|---|
| **Page load** | Page Starts/Finishes Loading, Home One/Three … Loading | page start / finish (217) | preloader fades, hero text rises in | Preloader + Reveal |
| **Scroll reveal** | Reveal, Card item scroll into view, Stories Scroll Into Viewport, New Scroll Animation | scroll into view (19) | fade + slide up, once | Reveal |
| **Scroll-linked motion** | Hero Text Parallax, Partners/Awards/Contact BG Parallax, Project Scroll Scale, Images/Logo/Footer Row Scrolling, Gallery/Phone Side Scroll, Diagonal Scrolling | while scrolling (49 + 1 page scroll) | parallax, scale-on-scroll, rows sliding sideways | Parallax, Marquee (in their stripes) |
| **Letter-by-letter text** | (custom code, not Webflow) `.tricks` | in view | each letter animates in, staggered | AnimatedText |
| **Count-up** | (custom code: countUp.js) | in view | numbers count up (Act; 10 project stats) | Stat |
| **Hover** | Button / Nav Link / Underline Link / Social icon / Partner Logo / Map Pin / Project / Card item / Image Scale hover in-out, Project Video Reveal | mouse over/out (306) | underline grows, arrow slides, image scales, project tile plays its video | Button, Link, ProjectTile, LogoRow |
| **Cursor follow** | View Project Hover | mouse move (133) | a "View project" label follows the cursor over tiles | ProjectTile |
| **Click / toggle** | Open/Close Menu, Modal Open/Close, Open/Close Faq, Read More/Less Testimonial, Sustainability Card Open/Close, Services Tab 1–3, Rotate Work View, About Accordion | click / second click (49) | menu, modals (credits, press, awards), read more/less, tabs, grid/list switch | Nav, Modal, Disclosure, Tabs |
| **Background change** | Background Gradient In/Out, Background Opacity | scroll | page background colour shifts between sections (Home, Act, Empower Children) | a stripe setting: background tone |

Animation kinds used: move (219), opacity (88), rotate (83), scale (44),

## 9. Things to decide or know before step 2

1. **The site is 11 layouts, not 12–15.** The project pages are one layout with
   free stripe lists. That's good news, but it means each project's content file
   is mostly a stripe list, so the move script in step 6 has to turn hand-built
   Webflow pages into stripes. The mapping in `scripts/inventory/stripe-lists.ps1`
   already does that for every page.
2. **News shows only 100 of 202 posts** (Webflow's limit). An exact copy would
   keep that limit. Showing all 202 would be a phase-2 improvement. Your call.
3. **Two broken addresses**, linked from old news posts. The plan is redirects
   in step 7. Where should they point?
   - `/work/sleepless` (2 posts about *Repeat Until Death*) → almost certainly
     `/work/sleepless-repeat-until-death`.
   - `/work/flags` (3 posts about *The Journey of Hope*, featuring Flags by SYML)
     → that project is no longer on the site. Redirect to `/work`, or bring it
     back?
4. **The 404 page title is still the Webflow template's.** A copy keeps it (phase
   1), and fixing it is a one-line phase-2 change.
5. **Tools:** this computer has no Node.js, npm or git yet. Step 4 needs all
   three, and installing them needs your yes.
